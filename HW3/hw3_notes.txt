| Param    | Controls (Intuition)                                 | Increase → EKF behaves like…                                    | Decrease → EKF behaves like…                              | Use when…                                                           |
| -------- | ---------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------- |
| **q_v0** | Base **linear** process noise (v), always on         | Less trust in straight odom; tags correct x,y more; more wiggle | More trust in straight odom; tags have weaker effect      | Up if straight odom is unreliable; down if it’s very good           |
| **q_v1** | Extra linear noise scaling with |v|                  | Fast motion = very uncertain; tags strongly correct at speed    | Even at high speed, still trusts odom                     | Up if long fast runs drift; down if high-speed odom is solid        |
| **q_w0** | Base **angular** process noise (w), turns in general | Less trust in rotations; tags can fix θ a lot                   | Very confident in θ from odom; tags barely adjust heading | Up if heading after turns is off; down if rotation model is perfect |
| **q_w1** | Extra angular noise scaling with |w|                 | Big turns = very uncertain; tags heavily correct θ              | Big turns still trusted; less correction from tags        | Up if large turns break map; down if large turns are accurate       |
| **r0**   | Base **range** noise (close tags)                    | Trust range less; weaker pull on pose/landmarks                 | Trust range more; stronger corrections from distance      | Up if ranges are noisy; down if ranges are clean/consistent         |
| **r1**   | Range noise growth with distance                     | Far tags influence less                                         | Far tags influence strongly                               | Up if far tags are flaky; down if far tags are reliable             |
| **b0**   | Base **bearing** noise (angle), close tags           | Trust bearing less; weaker θ correction                         | Trust bearing more; strong θ correction from tags         | Up if bearings jumpy; down if you need tags to fix heading          |
| **b1**   | Bearing noise growth with distance                   | Far-tag bearings matter less                                    | Far-tag bearings still strongly affect θ                  | Up if far bearings unreliable; down if they’re good                 |

	
	
For any of these (linear or angular):

Deadzone ↑

More “kick”, less subtle.

Helps with stiction, hurts fine control.

Deadzone ↓

Smoother, but might not move.

Slope ↑

Softer / slower response (for same commanded v or w).

Use if robot overshoots.

Slope ↓

Stronger / faster response.

Use if robot is sluggish.

If you tell me “it’s doing X when I try Y” (e.g., spins in place on diamond, arcs too much on straight), I can point at exactly which of the four knobs to nudge and in which direction.
