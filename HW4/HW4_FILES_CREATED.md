# HW4 Solution - Files Created

## Summary

This document lists all **new files created** for the HW4 A* path planning solution.

---

## New Python Source Files

### 1. `hw4_planning/hw4_planning/astar_planner.py`
**Purpose**: A* pathfinding algorithm implementation  
**Size**: ~300 lines  
**Key Class**: `AStarPlanner`  
**Functionality**:
- Grid-based path planning with A* search
- World↔grid coordinate conversion
- Occupancy grid building with obstacle inflation
- 8-connected movement (cardinal + diagonal)
- Euclidean distance heuristic

**Entry Point**: Used by `planning_node.py`

---

### 2. `hw4_planning/hw4_planning/hw4_config.py`
**Purpose**: Centralized configuration for HW4  
**Size**: ~80 lines  
**Type**: Configuration constants (no classes)  
**Configurable**:
- World bounds (8 ft × 8 ft = 2.44 m × 2.44 m)
- Obstacle definition (2 ft × 2 ft central structure)
- Grid resolution (5 cm/cell)
- Inflation radii (safety vs. fast modes)
- Robot control gains (Kv, Kw, velocity limits)
- AprilTag positions for localization
- Start/goal positions

**Usage**: Imported by other modules via `from . import hw4_config as cfg`

---

### 3. `hw4_planning/hw4_planning/planning_node.py`
**Purpose**: Main orchestrator - bridges A* planner and waypoint follower  
**Size**: ~200 lines  
**Key Class**: `Hw4PlanningNode(Node)`  
**Responsibilities**:
1. Initialize A* planner with world config
2. Build occupancy grid with configured obstacles
3. Plan path from start to goal
4. Convert path → waypoints with heading
5. Launch waypoint follower node
6. Log occupancy grid for debugging

**Entry Point**: ROS2 node executable `planning_node`  
**Publishes**: None (coordination only)  
**Subscribes**: None (standalone)

---

### 4. `hw4_planning/hw4_planning/waypoint_follower_hw4.py`
**Purpose**: Robot control - follows waypoints generated by planner  
**Size**: ~350 lines  
**Key Class**: `WaypointFollowerHW4(Node)`  
**Functionality**:
- Subscribes to `/pose_estimated` for pose feedback
- Implements proportional guidance law
- Differential drive motor command generation
- State machine: TRACKING → COAST → SEARCH → FAILSAFE
- CSV logging of execution
- Handles pose loss gracefully with search behavior

**ROS2 Integration**:
- **Publishes**: `/motor_commands` (Float32MultiArray)
- **Subscribes**: `/pose_estimated` (PoseStamped)
- **Frequency**: 20 Hz control loop

**Entry Point**: ROS2 node executable `waypoint_follower_hw4`

---

### 5. `hw4_planning/hw4_planning/localization_hw4.py`
**Purpose**: Pose estimation using AprilTag detections  
**Size**: ~150 lines  
**Key Class**: `LocalizationNode(Node)`  
**Features**:
- Transformation utilities (4×4 matrices, quaternions)
- AprilTag detection handling
- Pose estimation relative to world frame
- ROS2 TF2 integration

**ROS2 Integration**:
- **Publishes**: `/pose_estimated` (PoseStamped)
- **Subscribes**: `/apriltag_pose` (PoseStamped)

**Entry Point**: ROS2 node executable `localization_hw4_node`

---

### 6. `hw4_planning/test_planner.py`
**Purpose**: Offline testing and visualization (no ROS required)  
**Size**: ~300 lines  
**Functions**: Command-line test utility  
**Features**:
- Test A* algorithm without ROS
- Visualize occupancy grid (ASCII art)
- Display planned path and statistics
- Validate path (check for obstacles)
- Save grid visualization to file

**Usage**: 
```bash
python3 test_planner.py [--mode safety|fast] [--show-grid] [--save-grid]
```

**Dependencies**: numpy, scipy (no ROS needed)

## Running the Solution

### Before First Run
1. Build package: `colcon build --packages-select hw4_planning`
2. Source workspace: `source install/setup.bash`
3. Test offline: `python3 hw4_planning/test_planner.py`

### Main Execution
```bash
# Safety mode (recommended)
ros2 launch hw4_planning hw4_astar_planning.launch.py

# Fast mode
ros2 launch hw4_planning hw4_astar_planning.launch.py planner_mode:=fast
```

### Output Files Created
- `~/hw4_log.csv` - Execution log
- `~/occupancy_grid.txt` - Grid visualization
